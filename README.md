# صوت الحارة — استطلاعات آراء سكان الحارة

تطبيق ويب عربي بسيط واحترافي لجمع استطلاعات آراء سكان الحارة حول المرشحين لمنصب المختار.
يعمل الآن بخادم مشترك: **الدخول برقم الشارع + اسم المستخدم (بدون كلمة سر)**، وكل من يدخل بنفس معلومات الدخول — من أي جهاز — يرى نفس الاستطلاع ونفس الأصوات ويقدر يكمل معك.

> استطلاع آراء غير رسمي فقط: النتائج تعبر عن الأصوات التي سجلها جامع الاستطلاع، وليست نظام اقتراع رسميًا.

## المزايا

- **دخول بمعلومات قابلة للمشاركة**: رقم الشارع + اسم المستخدم. إذا صاحبك صوّت على شارع 44 وبعتلك معلومات دخوله، تدخل بنفسها وتجد نفس الأصوات وتكمل.
- **تسجيل صوت فوري**: ضغطة واحدة على المرشح فيُسجل الصوت — بدون نافذة اسم. الاسم يُضاف لاحقًا من «سجل المصوتين» (اختياري).
- إدارة مرشحين بعدد غير محدود: إضافة، تعديل، حذف بتأكيد.
- **التراجع عن آخر صوت** مع تأكيد.
- لوحة تحكم: إجمالي الأصوات، عدد المرشحين، النسب المئوية، الترتيب، ورسم بياني يتحدث فورًا.
- سجل الأشخاص المصوتين (إدارة فقط): بحث، إضافة اسم لاحقًا، تعديل، حذف بتأكيد.
- صفحة نتائج احترافية + تصدير PDF (يدعم العربية وRTL) و Excel (XLSX) ومشاركة النتائج عبر واتساب.
- **مشاركة معلومات الدخول** عبر واتساب بضغطة زر (من الترويسة أو من إدارة الاستطلاع).
- سجل نشاط كامل بالتوقيت، تصفير الأصوات وحذف الاستطلاع بتأكيد مزدوج.
- تذكّر آخر دخول على الجهاز (دخول تلقائي) وقائمة دخول سريع للاستطلاعات السابقة.

## البنية

```
server.js            — خادم Node.js (بدون أي اعتماديات خارجية): API + ملفات ثابتة
data.json            — قاعدة البيانات (ملف JSON، يُنشأ تلقائيًا، غير مرفوع للريبو)
public/index.html    — الواجهة (عربية RTL)
public/css/styles.css— التصميم المتجاوب
public/js/app.js     — منطق الواجهة والاتصال بالخادم
```

## التشغيل

يتطلب Node.js 18 أو أحدث. لا حاجة لأي تثبيت اعتماديات:

```bash
node server.js                # يعمل على المنفذ 3000
# أو:
PORT=8080 DATA_FILE=/path/data.json node server.js
```

ثم افتح `http://localhost:3000` في المتصفح. البيانات تُحفظ في `data.json` — خذ نسخة منه دوريًا.

## ملاحظات

- لا يوجد تحقق من الهوية: أي شخص تعرفه معلومات الدخول يدخل ويصوت — شاركها فقط مع من تثق به.
- المكتبات (Chart.js، SheetJS، jsPDF، html2canvas) تُحمَّل من CDN — يحتاج إنترنت عند أول تحميل.
- غيّر رقم الشارع أو اسم المستخدم غير ممكن بعد الإنشاء (هما هوية الاستطلاع)؛ اسم الشارع للعرض قابل للتعديل من إدارة الاستطلاع.
