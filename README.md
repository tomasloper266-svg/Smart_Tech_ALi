# صوت الحارة — استطلاعات آراء سكان الحارة

تطبيق ويب عربي بسيط واحترافي لجمع استطلاعات آراء سكان الحارة حول المرشحين لمنصب المختار.
كل جامع أصوات ينشئ استطلاعًا مستقلًا خاصًا به (بيانات شارعه، مرشحوه، أصواته، سجلاته) — لا دمج تلقائي بين الاستطلاعات.

> استطلاع آراء غير رسمي فقط: النتائج تعبر عن الأصوات التي سجلها جامع الاستطلاع، وليس نظام اقتراع رسميًا.

## المزايا

- إنشاء استطلاع جديد (اسم الشارع، رقمه، اسم جامع الأصوات، تاريخ تلقائي) وتعديله لاحقًا.
- إدارة مرشحين بعدد غير محدود: إضافة، تعديل، حذف بتأكيد.
- تسجيل صوت بخطوتين: زر «تسجيل صوت» ثم «تأكيد» — مع الاسم أو بدونه.
- تنبيه عند إدخال اسم مسجل مسبقًا (تنبيه فقط، القرار للمستخدم — الأسماء المتشابهة مسموحة).
- التراجع عن صوت مسجل بالخطأ مع تأكيد.
- لوحة تحكم: إجمالي الأصوات، عدد المرشحين، النسب المئوية، الترتيب، ورسم بياني يتحدث فورًا.
- سجل الأشخاص المصوتين (إدارة فقط): بحث، تعديل، حذف بتأكيد، إجمالي الأسماء.
- صفحة نتائج احترافية + تصدير PDF (يدعم العربية وRTL) و Excel (XLSX) ومشاركة عبر واتساب.
- نسخ احتياطي JSON (تصدير/استيراد) وتصفير الأصوات وحذف الاستطلاع بتأكيدات إضافية.
- حفظ تلقائي محلي (localStorage) — البيانات على الجهاز نفسه ولا تُزامَن بين الأجهزة؛ انقلها بالنسخة الاحتياطية.

## التشغيل

تطبيق ثابت بالكامل (HTML + CSS + JavaScript) — لا حاجة لخادم أو قاعدة بيانات أو مفاتيح API.

- محليًا: افتح `index.html` في المتصفح، أو اعرض المجلد بأي خادم ملفات ثابت.
- المكتبات (Chart.js، SheetJS، jsPDF، html2canvas) تُحمَّل من CDN — يحتاج الإنترنت عند أول تحميل.

## النشر على GitHub Pages

1. افتح المستودع على GitHub: **Settings** ← **Pages**.
2. تحت **Build and deployment**، اختر **Source: Deploy from a branch**.
3. اختر **Branch: main** والمجلد **/ (root)**، ثم **Save**.
4. بعد دقيقة إلى دقيقتين سيصبح التطبيق متاحًا على:
   `https://<اسم-الحساب>.github.io/Smart_Tech_ALi/`

للتحديث: أي دفع (push) جديد على `main` يُحدِّث الموقع تلقائيًا.

## البنية
